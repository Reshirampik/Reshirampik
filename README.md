## 🚀 Featured project

### [car-dealership](https://github.com/Reshirampik/car-dealership)

A Java backend for a multi-role car dealership management system.

- REST API built with **Spring Boot**
- Data persistence with **PostgreSQL** and **Spring Data JPA**
- Database versioning with **Liquibase**
- Authentication and authorization with **Spring Security** and **Keycloak**
- Asynchronous service communication with **RabbitMQ**
- Service-to-service communication with **gRPC**
- Automated tests with **JUnit** and **Testcontainers**

<sub>Java 21 · Spring Boot 3 · Gradle · PostgreSQL · RabbitMQ</sub>
